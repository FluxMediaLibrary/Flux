# Support

Use GitHub Discussions for setup help, deployment questions, and general troubleshooting:

https://github.com/IDKDeadXD/Flux/discussions

Open an issue when you have a reproducible bug or a concrete feature request.

Before asking for help, include:

- Flux commit or release version.
- Deployment method, such as Docker Compose, local development, VPS, or Android.
- Relevant logs with secrets removed.
- Browser/device details for playback issues.

Do not post passwords, JWT secrets, TMDb keys, SMTP credentials, keystores, private media paths containing sensitive names, or full production database dumps.
